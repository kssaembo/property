# 검증 결과

검증일: 2026-11-12 (Asia/Seoul). Windows, Node.js 24.20.0, TypeScript 5, React 19, Vite 7.3.8, Vitest 5.1.0. 정확한 의존성은 package-lock.json에 고정되어 있습니다.

## 실행 결과

- `npm test`: **40개 통과, 실패 0개**.
- `npm run build`: TypeScript 검사 및 정적 번들 생성 성공.
- 의존성 설치 후 npm audit 요약: **알려진 취약점 0개**. 최초 발견한 테스트 도구 취약점은 Vitest 5.1.0으로 갱신해 해소했습니다.
- 빌드 시 Zod 내부 주석의 Rollup annotation 경고가 발생합니다. 번들 생성은 성공하며 해당 주석만 제거됩니다.
- 앱 브라우저 콘솔 오류 조회: 관찰 구간에서 오류 0개.

## 실제 브라우저에서 수행한 검사

가상 테스트 학생 2명, 자리 1개, 매매 1건과 직접 만든 테스트 배치도 PNG를 사용했습니다. 실제 학생 개인정보는 사용하지 않았고 소스에 초기 자료로 주입하지 않았습니다.

1. 빈 초기 화면: 자리/가격/거래 수가 0이며 자동 예시 데이터 없음.
2. 학생 A/B 등록, 자리 1 등록: 최초 낙찰가 100, 시세 150.
3. A → B 매매 120 등록: 소유자·사용자가 B, 최근 매매가 120, 시세는 150 유지.
4. PNG 업로드 성공.
5. 이미지 클릭으로 마커 배치, 마커 드래그, 위치 저장 성공.
6. 새로고침: 자리·계약·배치도·마커 유지 확인.
7. 390px 뷰포트: 한 열 레이아웃 확인, 문서 너비가 뷰포트를 넘지 않음. 마커의 left/top은 화면 변경 전후 `38.3528% / 32.8108%`로 유지. 모바일 캡처 도구가 불안정하여 모바일 전체 화면의 육안 검증은 제한적입니다.
8. 공통 JSON 다운로드 후 동일 파일 재가져오기: 신규 0 / 변경 없음 6 / 충돌 0 확인.
9. 최종 승인 후 거래 수 1 유지.
10. 새 기간 생성·통계 조회: 매매 1건, 평균 120권 유지. 생성 시점 배치도·소유 현황 표시.

브라우저 왕복에서 처음에는 JSON 필드 순서 차이로 충돌 오탐이 확인되었습니다. 정규화 비교로 수정하고 자동 회귀 테스트와 브라우저 재검사를 완료했습니다.
