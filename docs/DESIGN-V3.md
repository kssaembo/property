# 살아 있는 교실 · v3

## 구현

- 창문·나무 바닥·책장·식물·방석이 있는 새 교실 그림과 책상/캐릭터 PNG를 사용합니다. ZEP에서 느껴지는 픽셀 공간의 분위기를 참고한 독자적인 에셋입니다.
- 기존 상단바와 6개 모둠, 27개 자리, 아래쪽 칠판을 유지합니다. 교실은 화면 크기에 맞춰 축소하여 페이지 스크롤을 없앱니다. 입력창과 긴 목록만 내부 스크롤합니다.
- 8명의 가상 캐릭터가 통로를 따라 움직입니다. 55초마다 쉬는 시간, 독서, 수업, 기지개, 모둠 대화, 창밖 구경을 순환합니다. 이동 속도·대기 시간·쉬는 시간 목적지에 변화를 줍니다.
- 20개 짧은 대화 쌍이 순환합니다. 실제 학생 자료나 시세에 반응하는 생성형 대화가 아니며 외부 AI 호출이 없습니다.
- 다른 탭으로 전환하면 이동 계산을 쉬고, 돌아왔을 때 순간이동하지 않습니다. 설정에서 정지할 수 있고 운영체제의 동작 줄이기 설정도 따릅니다.
- 그림은 정면·옆모습·뒷모습·독서 자세를 담은 시트입니다. 이동에 따라 방향을 바꾸며 CSS로 걸음과 몸짓을 표현합니다. 정교한 다프레임 게임 애니메이션이나 실시간 접속 기능은 아닙니다.

## 생성 에셋과 제작 지시 요약

내장 이미지 생성 도구로 제작했으며 외부 이미지 서비스에 직접 요청하지 않았습니다. 참고 이미지는 사용자가 제공한 메타버스 사무실 이미지입니다.

- src/assets/room.png: 밝고 아늑한 픽셀 교실, 위쪽 창문과 낮은 수납장, 넓은 빈 나무 바닥, 양옆 식물·책장·독서 방석, 책상과 인물·문자 없는 2.5D 배경.
- src/assets/people.png: 투명 배경의 4×4 정렬 캐릭터 시트. 각 행은 다른 학생, 열은 정면 서기·옆으로 걷기·뒤로 걷기·앉아서 독서. 작은 머리보다 큰 머리 비율, 따뜻한 색, 명확한 픽셀 윤곽.
- src/assets/desk.png: 투명 배경의 나무 책상과 녹색 의자, 책과 필기도구, 교실 배경과 같은 위에서 내려다보는 시점, 글자 없음.
- public/classroom-icon.png: 앞 버전에서 생성한 거래소 아이콘을 유지했습니다.

## 검증

자동 테스트 64개: 기존 계약/데이터/배치 47개 + 공개 데이터 제거·원본 불변·스크립트 삽입 방어·이동 경로/범위·GitHub 게시 충돌/권한/대상 검증 17개. TypeScript 검사와 운영 빌드 통과. 브라우저에서 교실 27석/캐릭터 8명, 페이지 스크롤 없음, 익명 게시 미리보기, 전체 화면 미리보기, 읽기 전용 자리 정보와 시세 그래프 확인.

## 다음 개선 제안

더 다양한 걷기 프레임과 손짓 스프라이트, 수업/쉬는 시간 비율 설정을 추가하면 분위기를 더 세밀하게 조절할 수 있습니다. 현재 버전은 서버 비용 없이 돌아가는 관찰용 교실을 우선했습니다.
