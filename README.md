# 우리 반 부동산 거래소

React · TypeScript · Vite로 제작한 교실 자리 소유권 및 계약 관리 앱입니다. 별도 백엔드, 로그인, 원격 데이터 저장, 실제 금융거래가 없습니다. 앱을 실행해도 예시 자료를 자동으로 넣지 않습니다.

## 실행

Node.js 22.18 이상(개발·검증: Node 24)을 설치한 환경에서 이 폴더의 터미널을 열어 실행합니다.

```sh
npm ci
npm run dev
```

화면에 표시된 로컬 주소를 엽니다. `npm test`는 자동 테스트, `npm run build`는 배포용 `dist/` 생성 명령입니다. `dist/`를 정적 웹 호스팅에 업로드할 수 있습니다. 파일을 더블 클릭하는 `file://` 실행은 지원하지 않습니다. 개발 서버는 화면 제공용일 뿐 업무 데이터 서버가 아닙니다.

## 처음 사용하기

1. ClassBank 파일을 사용한다면 **자료를 등록하기 전에 설정에서 학급 ID**를 동일하게 지정합니다.
2. 학생별 현황에서 학생을 등록합니다. 이름이 같아도 ID가 달라 별개 학생입니다.
3. 전체 부동산에서 자리번호, 기존 소유자, 최초 낙찰가격, 현재 시세를 등록합니다.
4. 배치도 이미지를 업로드하고 위치 편집에서 자리를 선택한 후 이미지를 클릭하거나 마커를 드래그하고 저장합니다.
5. 자리 상세에서 매매·전세·월세를 등록합니다. 매매는 소유권을 바꾸며 임대차는 사용자를 바꿉니다.
6. 정기적으로 공통 JSON과 **이미지 포함 전체 백업**을 내려받습니다.

## 제공 기능

- IndexedDB 저장: 자료·이미지·좌표·설정·변경 이력. 다른 탭의 오래된 쓰기 차단.
- 이미지 업로드/교체, 상대좌표 마커, 위치 편집·드래그, 확대, 마커 표시 설정.
- 학생 이름 수정, 자리 등록·수정, 시세 변경과 그래프, 학생별 보유/사용/계약 내역.
- 계약 등록·수정·종료·취소와 거래 이력. 후속 소유권 연결 및 임대차 충돌 검증.
- 기간별 조회와 통계, 기간 시작 현황의 세 가지 복사 방식.
- ClassBank 공통 JSON, CSV 부분 갱신, 가져오기 미리보기, 항목별 충돌 선택, 원자적 적용과 자동 백업.
- 전체 백업/복원에는 배치도·기간 스냅샷·수정 이력도 포함됩니다.

## 전달 파일

- `shared/exchange.ts`: 공통 Zod 검증기, TypeScript 타입, 직렬화 함수.
- `shared/exchange.schema.json`: JSON Schema 2020-12 구조 규격.
- `src/domain.ts`: 소유권·계약 충돌·시세·통계 규칙.
- `src/transfer.ts`: 가져오기 미리보기, 병합, CSV 변환.
- `src/storage.ts`: IndexedDB 저장·동시 수정 방지·가져오기 전 백업.
- `samples/`: 명시적으로 가져올 때만 적용되는 가상 예시와 CSV 양식.
- `docs/CLASSBANK.md`: 연동 규칙 및 ClassBank 적용 방법.
- `docs/TEST-REPORT.md`: 실제 검증 결과와 남은 수동 검증.
- `docs/DECISIONS.md`: 동작 기준, 제약, 개선 제안.

## 주의할 동작

소유권 이력이 있는 자리의 소유자를 직접 덮어쓰지 않습니다. 취소는 소유권을 다시 계산하지만 **매매 종료는 소유권을 되돌리지 않습니다**. 임대 종료일은 사용일에 포함됩니다. 계약 기간 중 매매는 차단하므로 임대 종료일 다음 날 이후에 매매하세요.

기간은 실제 계약을 유지하는 분류입니다. 세 가지 복사 방식은 기간 시작 참고 현황을 만들며, 기간별 통계의 현황 편집에서 참고 소유자를 새로 지정할 수 있지만 실제 장부의 소유권을 초기화하지 않습니다. 별도 독립 학급/새 학년도 장부로 자동 분리하는 기능은 포함하지 않습니다.

동일 공통 기준 버전이 확인되지 않은 외부 수정은 모두 충돌로 표시합니다. revision이나 시간만 보고 덮어쓰지 않습니다. 가져온 계약과 자리·거래기록이 일치하지 않으면 적용이 차단됩니다.

실제 ClassBank 프로젝트는 제공받지 않았습니다. 따라서 ClassBank 코드에 동일 스키마를 적용하거나 실제 서비스 간 왕복을 검증한 결과물은 아닙니다. 양쪽에 제공된 공통 모듈과 검증 규칙을 함께 적용해야 합니다.

IndexedDB는 브라우저·사이트 주소(포트 포함)별로 분리됩니다. 주소 변경, 브라우저 정리, 시크릿 모드 종료, 기기 변경에 대비해 파일 백업을 보관하세요. 기본 JSON에는 이미지·로컬 수정 이력·기간 시작 스냅샷이 포함되지 않습니다.
