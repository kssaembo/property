# 우리 반 부동산 거래소 · 살아 있는 교실 · 읽기 전용 게시 v3

React · TypeScript · Vite, 별도 백엔드 없이 IndexedDB로 작동하는 학급 자리·계약 관리 앱입니다.

## 실행

Node.js 22.18 이상을 설치하고 프로젝트 폴더에서 실행합니다.

```sh
npm ci
npm run dev
```

`npm test`: 자동 테스트 64개. `npm run build`: 정적 배포용 dist 생성. 관리 앱의 file:// 실행은 지원하지 않습니다. 별도로 생성한 읽기 전용 게시 HTML은 더블 클릭으로 볼 수 있습니다.

## 사용법

1. ClassBank 파일을 사용한다면 최초 자료 등록 전 설정에서 학급 ID를 맞춥니다.
2. 학생별 현황 탭에서 학생을 등록합니다.
3. 교실의 책상을 클릭해 기존 소유주·최초 낙찰가·시세를 입력합니다. 빈 책상 27개는 배치 틀이며 저장 전에는 부동산 자료가 아닙니다.
4. 등록한 책상을 클릭하고 계약 입력에서 매매·전세·월세를 등록합니다. 계약 수정·종료·취소도 자리 관리 모달에서 가능합니다.
5. 모둠 이름을 클릭하면 이름을 수정할 수 있습니다.
6. 책상에 마우스를 올리거나 키보드로 포커스를 주면 상세정보와 시세 그래프를 봅니다. 터치 화면에서는 클릭해 확인합니다.
7. 가져오기·내보내기에서 공통 JSON, CSV, 이미지·모둠 설정·이력 포함 전체 백업을 사용합니다.

## 화면 구성

첨부 참고 이미지 기준 27석: 위쪽 왼쪽부터 모둠 6·5·4(각 5명, 최상단은 오른쪽 자리만), 아래쪽 모둠 3·2·1(각 4명), 하단 칠판. 소개 문구·기간 UI·상시 우측 패널을 제거했습니다. 교실 전체는 한 화면에 맞추고 긴 목록과 입력 모달만 내부 스크롤을 사용합니다.

캐릭터는 실제 학생과 관계없는 가상 장식입니다. 설정에서 애니메이션을 끌 수 있습니다. 예시 학생이나 계약을 자동 등록하지 않습니다.

## 데이터와 게시

기존 학생·자리·계약·거래 ID는 그대로 보존합니다. 기간 UI와 이전 이미지 배치 UI는 제거했지만 기존 데이터와 백업은 유지합니다. 모둠 이름과 캐릭터 설정은 전체 백업에 포함되며 ClassBank 공통 JSON에는 포함되지 않습니다.

설정 → 읽기 전용 게시본 만들기에서 익명/별칭/실명을 선택하고 미리보기 후 독립 HTML을 내려받거나 GitHub Pages에 직접 게시할 수 있습니다. 원본 장부는 로컬에 남습니다. 자세한 설정·갱신·게시 취소 방법은 docs/PUBLISHING.md를 참고하세요.

IndexedDB는 기기·브라우저·사이트 주소(포트 포함)별로 분리됩니다. 브라우저 데이터 삭제 전 파일 백업을 보관하세요. 실제 ClassBank 프로젝트 적용과 서비스 간 왕복은 아직 미검증이며, 두 프로젝트가 동일한 공통 모듈을 사용해야 합니다.

## GitHub에 올릴 파일

src/, shared/, public/, scripts/, docs/, samples/와 프로젝트 루트의 설정 파일·package.json·package-lock.json·README.md·.gitignore를 포함합니다. **src/assets/, public/, scripts/build-viewer.mjs, viewer.html을 반드시 포함하세요. scripts 폴더는 이제 게시본 빌드에 필요하므로 제외하면 안 됩니다.** node_modules/, dist/, *.tsbuildinfo는 .gitignore에 따라 제외합니다.

## v3 추가 내용

새 교실 배경, 방향별 캐릭터와 독서 자세, 6가지 활동, 20개 대화 쌍을 적용했습니다. 실제 학생 접속 없이 관찰하는 교실입니다. 제작과 검증 내용은 docs/DESIGN-V3.md를 참고하세요.

## 문서

- docs/DESIGN-V2.md: 현재 디자인, 아이콘 생성 프롬프트, 실제 화면 검증
- docs/PUBLISHING-REVIEW.md: 게시 기능 검토
- docs/CLASSBANK.md: 공통 규격·연동 방법
- docs/TEST-REPORT.md: 최초 버전 검증 이력
- shared/exchange.ts, shared/exchange.schema.json: 공통 타입·검증 규격
- samples/: 수동으로 가져올 때만 사용하는 가상 예시

매매 종료는 소유권을 유지하고 취소는 소유권을 재계산합니다. 후속 소유권 연결을 깨는 취소, 임대차 중 매매, 중복 임대차는 차단합니다. 자동송금·자동환급은 하지 않습니다.
